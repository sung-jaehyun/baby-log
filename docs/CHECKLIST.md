# 제작 전 점검표

새 기능을 만들기 전에 아래를 먼저 정하고, 테스트(`tests/e2e.py`)에 넣는다.

## 공통 (모든 작업)
| 영역 | 확인할 것 |
|---|---|
| 데이터 유실 | 저장은 대기열로만, 실패해도 버리지 않음. 서버 응답이 이 기기의 최근 수정을 덮지 않음 |
| 동시 사용 | 3대가 같은 기록을 보거나 고칠 때 결과가 같은가. 늦게 도착한 응답 처리 |
| 인터넷 끊김 | 화면은 휴대폰 저장본으로 즉시. 끊겨도 동작, 연결되면 자동 반영 |
| 속도 | 탭·버튼 반응 0.1초 안(저사양 6배 느림 기준 0.2초). 계산은 화면 그릴 때 한 번만 |
| 화면 갱신 | 입력 중·손가락 닿은 중에는 뒤에서 다시 그리지 않음. 스크롤 위치 유지 |
| 경계값 | 기록 없음, 오늘(진행 중), 자정 넘는 잠, 밤중 깸, 열린 잠, 일정표 바뀐 날 |
| 보안 | 사용자 입력은 모두 esc() 후 화면에. 서버 주소·PIN 공개 금지 |
| 배포 | release.sh로 버전 올림 → 테스트 통과 → 독립 검토 → main |

## 패턴 탭 (2차-1)
| 항목 | 정한 것 |
|---|---|
| 기간 | 최근 7일: 오늘 포함 7일, ‹ ›로 7일씩. 주별: 월~일. 미래로는 못 감. 45일보다 오래된 기간은 서버에서 더 불러옴(그동안 기존 화면 유지) |
| 오늘 | 차트에는 지금까지만 그림. 평균·추이·목표 비교에서는 오늘을 뺌(진행 중이라 값이 작게 나옴) |
| 밤잠 | 하루 탭과 같은 규칙(잠든 날 기준/자정 기준 설정 따름). 차트는 0~24시로 날짜별로 잘라 그림 |
| 빈 날 | 기록 없는 날은 표에 "-", 평균·추이에서 제외(0으로 계산하지 않음) |
| 계획 변경 | 목표 vs 실제는 날마다 그날 적용된 일정표로 비교 후 평균 |
| 깨시 짝짓기 | 실제 낮잠 순서대로 1번째, 2번째… 마지막 깨시는 마지막 낮잠 끝→밤잠 시작 |
| 표시 항목 | 켜기·끄기는 기기별 저장(다른 사람 화면에 영향 없음) |
| 눌렀을 때 | 차트 막대·표의 날짜 → 그날 하루 탭 |
| 속도 | 차트·표·그래프 모두 한 번 계산. 45일 데이터 + 저사양에서 패턴 탭 열기 0.2초 안 |
