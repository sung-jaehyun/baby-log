# 제작 전 점검표

새 기능을 만들기 전에 아래를 먼저 정하고, 테스트(`tests/e2e.py`)에 넣는다.

## 공통 (모든 작업)
| 영역 | 확인할 것 |
|---|---|
| 데이터 유실 | 저장은 대기열로만, 실패해도 버리지 않음. 서버 응답이 이 기기의 최근 수정을 덮지 않음 |
| 동시 사용 | 3대가 같은 기록을 보거나 고칠 때 결과가 같은가. 늦게 도착한 응답 처리 |
| 인터넷 끊김 | 화면은 휴대폰 저장본으로 즉시. 끊겨도 동작, 연결되면 자동 반영 |
| 속도 | 탭·버튼 반응 0.1초 안(저사양 6배 느림 기준 0.2초). 계산은 화면 그릴 때 한 번만 |
| 화면 갱신 | 입력 중·손가락 닿은 중에는 뒤에서 다시 그리지 않음. 스크롤 위치 유지 |
| 경계값 | 기록 없음, 오늘(진행 중), 자정 넘는 잠, 밤중 깸, 열린 잠, 일정표 바뀐 날 |
| 보안 | 사용자 입력은 모두 esc() 후 화면에. 서버 주소·PIN 공개 금지 |
| 배포 | release.sh로 버전 올림 → 테스트 통과 → 독립 검토 → main |

## 패턴 탭 (2차-1)
| 항목 | 정한 것 |
|---|---|
| 기간 | 최근 7일: 오늘 포함 7일, ‹ ›로 7일씩. 주별: 월~일. 미래로는 못 감. 45일보다 오래된 기간은 서버에서 더 불러옴(그동안 기존 화면 유지) |
| 오늘 | 차트에는 지금까지만 그림. 평균·추이·목표 비교에서는 오늘을 뺌(진행 중이라 값이 작게 나옴) |
| 밤잠 | 하루 탭과 같은 규칙(잠든 날 기준/자정 기준 설정 따름). 차트는 0~24시로 날짜별로 잘라 그림 |
| 빈 날 | 기록 없는 날은 표에 "-", 평균·추이에서 제외(0으로 계산하지 않음) |
| 계획 변경 | 목표 vs 실제는 날마다 그날 적용된 일정표로 비교 후 평균 |
| 깨시 짝짓기 | 실제 낮잠 순서대로 1번째, 2번째… 마지막 깨시는 마지막 낮잠 끝→밤잠 시작 |
| 표시 항목 | 켜기·끄기는 기기별 저장(다른 사람 화면에 영향 없음) |
| 눌렀을 때 | 차트 막대·표의 날짜 → 그날 하루 탭 |
| 속도 | 차트·표·그래프 모두 한 번 계산. 45일 데이터 + 저사양에서 패턴 탭 열기 0.2초 안 |

## 성장 탭 (2차-2)
| 항목 | 정한 것 |
|---|---|
| 저장 | 기존 '기록' 시트에 새 종류로: growth(값=몸무게kg, 세부1=키cm, 세부2=장소), vax(세부1=접종 키 또는 이름, 세부2=병원, 세부3='선택'), checkup(세부1=차수), hospital(세부1=병원, 세부2=이유), milestone(세부1=항목), anniv(세부1=이름). 저장·재시도·동기화는 기존 대기열 그대로 |
| 오래된 기록 | 성장 종류와 이유식은 45일이 지나도 항상 불러오고(서버) 휴대폰에도 계속 보관(캐시) |
| 서버 버전 | 서버 API 3 미만이면 "서버 새 버전 배포 필요" 안내 |
| 백분위 | WHO 남아 LMS, 월령 사이 직선 보간, 0~24개월 누워 잰 키·이후 선 키. 36개월 이상은 표시하지 않음(국내 기준 자료 미포함) |
| 날짜 계산 | 생일 + N개월(월말은 그달 마지막 날로). 기간 끝 = 생일 + (끝 개월+1) − 1일 |
| 접종 상태 | 완료(기록 있음) / 아직(시작 전, D-n) / 지금 맞을 시기 / 시기 지남. 로타바이러스는 종류 선택(로타릭스면 3차 숨김), 일본뇌염은 사백신·생백신 선택 전 하나로 표시 |
| 검진 | 키·몸무게를 같이 넣으면 성장 기록도 함께 만듦 |
| 화면 분리 | 성장 종류 기록은 홈 최근 기록·하루 탭 목록에 나오지 않음 |
| 월간 리포트 | 지난 날만(오늘 제외), 기록 있는 날 평균. 지난달과 비교. 오래된 달은 서버에서 더 불러옴 |
| 입력 검사 | 몸무게 1~30kg, 키 30~130cm, 미래 날짜 금지, 생일 이전 금지 |

## 새 디자인 (3차, 가계부 느낌 파스텔)
| 항목 | 정한 것 |
|---|---|
| 꾸미기 저장 | 테마·글씨체·글씨 크기·사진 2장은 이 휴대폰에만 저장(localStorage 'look'·'photo:*'). 서버로 안 보냄, 다른 가족 화면에 영향 없음 |
| 첫 화면 깜빡임 | index.html 머리에서 테마·글씨체·크기를 먼저 적용(앱 코드보다 먼저) |
| 테마 | 라벤더(기본)·피치·민트·스카이·레몬·다크. 색은 style.css 변수로만. 기록 종류 색(밤잠·낮잠·수유 등)은 테마와 관계없이 같음 |
| 글씨체 | 프리텐다드(기본)·나눔고딕·주아·개구·푸어 스토리. 글씨 파일은 저장소에 두고(외부 서버 안 씀), 고른 글씨체 파일만 필요한 글자 조각만 받음. 받은 파일은 휴대폰에 보관(fonts 캐시, 앱 버전 바뀌어도 유지) → 인터넷 끊겨도 보임 |
| 글씨 크기 | 작게 0.92 · 보통 1 · 크게 1.1 (화면 전체 배율) |
| 사진 | 갤러리에서 고름 → 정사각형으로 잘라 240px JPEG로 줄여 저장(약 20KB). 저장 공간 부족하면 안내하고 기존 사진 유지. '기본 그림'으로 되돌리기 |
| 기록자 표시 | 목록·메모·중복 확인 문구에는 사람 이름 안 보임. 기록을 눌러 연 수정 창에만 '기록한 사람 · 이름'(4차에서 변경). 시트에는 계속 저장 |
| 홈 한 화면 | 390×844(갤럭시 보통 크기)에서 알림 1개까지 스크롤 없이 한 화면. 남는 높이만큼 원형 시계가 커지고(110~210px), 모자라면 작아짐. 글씨 크게·알림 여러 개면 스크롤 허용 |
| 홈 알림 | 기념일(당일·하루 전), 접종·검진 시기(지금 맞을 시기인 것), 오늘 하루 메모만. 체온·대변 알림 없음 |
| 홈 남은 일정 | 다음 잠·다음 수유는 실제 기록으로 다시 계산한 시각, 그 뒤 항목은 일정표 시각. 지난 항목은 안 보임 |
| 하루 탭 | 계획 대비는 시간순 목록 6개 + 더 보기, 기록 전체는 5개 + 더 보기 |
| 패턴·성장 하위 화면 | 패턴: 주간 그래프(첫 화면)·7일 비교·추이·목표 / 성장: 키·몸무게(첫 화면)·건강·발달·기념일. 하단 탭을 누르면 첫 화면으로 |
| 주간 그래프 | 시간 눈금 3시간마다 + 점선, 대변은 작은 똥 그림 |
| 발달 '다음에 기대돼요' | 아직 기록 안 한 발달 중 지금 월령 무렵 것만, 누르면 오늘 날짜로 바로 기록(목록에서 날짜 수정·삭제 가능) |
| 설정 | 묶음 목록 → 누르면 그 항목만 고치는 창. 저장은 기존 saveSettings 순서 보장 그대로 |
| 속도 | 테마 바꾸기·모든 탭 이동 저사양 6배 느림 기준 0.2초 안. 글씨체는 누른 표시가 바로(0.2초 안) 보이고, 화면 전체 글씨 적용은 0.5초 안(글자 전체를 다시 배치해야 해서) |

## 기록 지우기 (3차, 서버 API 4)
| 항목 | 정한 것 |
|---|---|
| 누가 | 사용자 목록 맨 위 사람(관리자)만. 메뉴도 관리자 휴대폰에만 보이고, 서버도 관리자인지 다시 확인 |
| 범위 | ① 매일 기록만(성장 탭 종류는 남김) ② 전부. 하루 메모는 둘 다 지움. 설정·일정표·가족·PIN·변경기록은 그대로 |
| 실수 방지 | 범위 고르기 + 내 PIN 다시 입력 + '지우기' 직접 입력. 서버도 PIN·확인 글자 검사 |
| 백업 | 지우기 전에 '기록_백업_날짜시각'·'하루메모_백업_날짜시각' 시트로 복사(되살릴 수 있음) |
| 다른 휴대폰 | 응답마다 마지막 지운 시각(reset)을 보냄 → 바뀐 걸 보면 휴대폰 저장본을 비우고 전체를 새로 받음 |
| 늦게 도착한 기록 | 대기열 항목마다 만든 시각(at, 옛 버전은 rec.created)을 붙여 보냄. 지운 시각 이전에 만든 '새 기록'·'하루 메모'는 서버가 'reset'으로 거절 → 휴대폰에서도 버림(매일 기록만 지운 경우 성장 기록은 받음). 수정·삭제는 그대로 보내고, 지워진 기록이면 '찾을 수 없음' → 버림. 휴대폰·서버 시계 차이는 보정 |
| 늦게 도착한 응답 | 지우기를 알게 된 뒤 도착한 옛 sync·range·batch 응답은 화면에 반영하지 않음. 옛 reset 값이 늦게 와도 무시 |
| 관리자 보호 | 맨 위 사람은 관리자 본인만 바꿀 수 있음(서버가 강제). 항상 사용 중 |
| 중간에 멈춤 | 백업 → 지운 시각 기록 → 비우기 순서. 비우는 중 멈춰도 옛 기록이 다시 올라오지 않음 |
| 관리자 대기 기록 | 지우기 전에 올리고, 못 올렸거나 저장 못 한 기록이 있으면 지우기를 멈춤 |
| 지우기 전 | 관리자 휴대폰의 대기 기록을 먼저 올려서 백업에 포함 |

## 4차 — 가상 사용자 피드백 반영 (2026-11-06)
| 항목 | 정한 것 |
|---|---|
| 뒤로가기 | 안드로이드 뒤로가기 = 열린 창 닫기 → (창 없으면) 홈 아닌 탭은 홈으로 → 홈에서는 한 번에 앱 종료. 기록(history) 칸은 필요한 수(창 1 + 홈 아닌 탭 1)만 유지: 누른 직후에만 쌓고(크롬은 터치 없이 쌓은 칸을 건너뜀) 뒤로가기 처리 중엔 안 쌓음, 버튼으로 창을 닫아 남은 칸은 조용히 꺼냄. 첫 PIN 변경 창은 안 닫힘. 확인 창(ask)을 뒤로가기로 닫으면 '취소'. 사진 위치 맞추기 화면은 자기 처리 유지 |
| 분유 양 | 입력창·수정 창·지난 기록 추가 모두 5~400ml. 밖이면 안내하고 저장 안 함 |
| 지금 할 일 한 줄 | 깨어 있을 때 상태 카드 제목 아래: 다음 잠·수유 중 먼저 오는 것. 15분 이내면 '곧 ○○ 시간이에요', 지나면 '○○ 시간이 지났어요'(하나 지나고 하나 곧이면 '○○ 시간이 지났어요 · 곧 ○○'), 아니면 '다음은 ○○ · 시각쯤'. 3시간 넘게 지난 수유 예상은 뺌(남은 일정과 같은 기준). 잘 때·밤중은 기존 문구 |
| 다음 수유 이름 | 오늘 몇 번 먹었는지가 아니라 예상 시각과 가장 가까운 일정표 수유 이름(90분 안). 그 뒤 일정은 그 다음 수유부터. 수유를 많이 한 날에도 막수가 당겨지거나 사라지지 않음 |
| 토막잠 | 20분 미만으로 끝난 낮잠은 '몇 번째 낮잠' 셀 때 뺌(하루 합계·횟수엔 포함). 일정표 낮잠을 다 잤는데 밤잠까지 (마지막 깨시+90분)보다 많이 남으면 '추가 낮잠' 안내, 아니면 밤잠 |
| 저장 안내 | 체크 + '저장됐어요' 크게, 아래 '기록 내용 · 시각'. 5초(진동 없음), 남은 시간 막대. 저절로 닫히면 홈 '마지막 기록' 칸이 그 기록일 때 2초간 '✓ 방금 저장' |
| 하루 요약 공유 | 하루 탭 '이 날 요약 공유' → 이미지(분유·낮잠·밤잠·기저귀·목욕·메모) → 폰 공유 창. 공유 창 없는 기기는 이미지 저장. 값은 하루 탭 합계와 같은 계산. 단 오늘을 공유하면 밤잠 칸은 '어젯밤'(홈과 같은 기준, 자정 기준 설정이면 오늘) |
| 병원용 리포트 | 성장 > 건강 맨 위. 최근 7·14·30일(오늘 제외, 생일 전 제외). 평균은 기록 있는 날만. 날짜별 표·특이 기록(체온 기준값 이상, 묽은 변, 확인 필요 색, 투약, 병원)·성장·접종. 'PDF로 저장 · 인쇄'는 리포트만 인쇄. 45일보다 이전 기간은 서버에서 더 불러온 뒤 다시 그림 |

## 4-1차 — 오늘 남은 일정 유동화 (2026-11-06, 실사용 중 발견)
| 항목 | 정한 것 |
|---|---|
| 문제 | 하루가 밀리면 다음 것 하나만 실제 기준이고 나머지는 일정표 시각이라 순서가 꼬임(예: 19:40 밤잠 → 19:55 수유) |
| 계산 | 실제 깬 시각(또는 지금 자는 잠의 예상 깸)에서 목표 깨시 → 낮잠(일정표 길이) → 목표 깨시 … → 밤잠 순으로 이어서 계산. 수유는 실제 마지막 수유 + 수유 간격으로 이어서 |
| 밤잠 | 깨시대로 밀거나 당기되 일정표 ±30분 안. 늦어지면 마지막 낮잠을 줄여 안내('낮잠4 (27분만)', 최소 20분). 밤잠 30분 전 이후에 시작할 낮잠은 뺌. 낮잠을 다 잔 뒤 상태 카드의 밤잠 예상도 같은 기준 |
| 목욕·막수 | 일정표 간격(밤잠 40분 전·20분 전)대로 밤잠을 따라 움직임. 목욕 기록이 있으면 목욕 뺌. 막수 시각 60분 전~밤잠 사이에 이미 먹었으면 막수 뺌 |

## 7·8차: 하루 탭 기록 목록 + 계획 대비 (2026-11-07)
| 항목 | 정한 것 |
|---|---|
| 새벽 깸·기상 | 밤잠에서 깬 시각을 이 날 목록에 따로 한 줄(☀️). 마지막으로 깬 것 = 기상, 그 전(다시 잠든 경우) = 새벽 깸. 예) 05:00 새벽 깸 → 05:10 새벽 수유 → 05:20 밤잠 → 07:00 기상. 누르면 그 밤잠 수정 |
| 새벽 수유 | 아침 기상 전 수유(기상 기록이 없으면 밤 시간대·오전)는 목록에서 '새벽 수유'(아래 작게 분유 N ml). 계획 대비 표에는 넣지 않음. 패턴 탭 첫 수유도 같은 기준 |
| 다시 자는 중 | 새벽에 깼다가 다시 잠들어 아직 자는 중이면 아직 기상 아님(앞서 깬 건 새벽 깸, 기상 비교는 '아직') |
| 추가 수유 | 앞에 짝지은 수유와 간격이 목표 텀의 절반 미만이면 추가 수유로 빼고 짝 순번을 쓰지 않음. 수유텀은 앞 '짝지은' 수유 기준 |
| 토막잠 | 깨시를 잴 때 토막잠(20분 미만)은 건너뜀. 낮잠 바로 앞(30분 안)에 토막잠이 있으면 처음 재운 시각(토막잠 시작)까지를 깨시로. 패턴 탭 깨시 통계는 기존대로(토막잠 포함) |
| 요약 4칸 | 수유 N회 / N ml, 낮잠 N회 / N시간 N분, 밤잠 / 총 N시간 N분(최장 표시 없음), 기저귀 |
| 일정 탭 날짜 | 다가오는 일정 날짜는 월/일, 올해가 아니면 아래 작게 'YYYY년' |
| 순서 | 기록 목록은 아침부터 시간순. 접으면 최근 5건 + 위에 '앞의 기록 N건 더 보기' |
| 계획 대비 | 따로 카드 없이 기록 카드 안 요약 한 줄(“N개 중 M개 계획대로 · 어긋난 것 2개”), 누르면 표 펼침. 오늘이면 '다음 계획 · 홈 남은 일정의 첫 항목' |
| 비교 기준 | 낮잠 = 깨시(잠든 시각 − 바로 앞 깬 시각) vs 일정표 깨시, 수유 = 수유텀(바로 앞 수유와 간격) vs 일정표 간격 → ±15분이면 계획대로. 기상·첫 수유·목욕·밤잠 시작은 시각 비교 ±30분. 낮잠·수유는 순서대로 짝(토막잠·새벽 수유 제외) |
