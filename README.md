# 아기 기록 앱

베이비타임을 뼈대로 만든 우리 가족 육아 기록 앱입니다.
화면은 GitHub Pages(PWA), 데이터는 구글 시트에 저장됩니다.

## 1. 구글 시트 + 서버 설치 (재현 계정, 컴퓨터에서 1번만)

1. [구글 드라이브](https://drive.google.com)에서 **새로 만들기 → Google 스프레드시트**, 이름을 `아기 기록`으로 바꿉니다.
2. 시트 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 왼쪽 `Code.gs`의 내용을 전부 지우고, 이 저장소의 `apps-script/Code.gs` 내용을 통째로 붙여넣은 뒤 저장(💾)합니다.
4. 위쪽 함수 선택 칸에서 **setup**을 고르고 **실행**을 누릅니다.
   - 권한 창이 뜨면 본인 계정 선택 → **고급 → (안전하지 않음)으로 이동 → 허용**. 본인이 만든 스크립트라 이렇게 뜨는 것이 정상입니다.
   - 시트로 돌아가면 `기록`, `사용자`, `설정` 등 탭이 생겨 있습니다.
5. `사용자` 탭에서 **PIN을 바꿉니다**(처음 값 1111/2222/3333). 숫자 4자리.
6. Apps Script 화면 오른쪽 위 **배포 → 새 배포**
   - 유형 선택(⚙️) → **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - **배포** → 나오는 **웹 앱 URL**(https://script.google.com/macros/s/.../exec)을 복사
   - "모든 사용자"여도 PIN이 맞아야만 기록을 읽고 쓸 수 있고, PIN을 10번 틀리면 1시간 잠깁니다.
   - 이 주소는 공개된 곳(이 저장소 등)에 올리지 마세요. 가족 링크로만 전달합니다.

> 서버 코드를 고친 뒤에는 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포**로 올려야 같은 주소가 유지됩니다.

## 2. GitHub Pages 켜기 (1번만)

저장소 **Settings → Pages → Build and deployment**
- Source: **Deploy from a branch**
- Branch: **main** / **(root)** → **Save**

1~2분 뒤 https://sung-jaehyun.github.io/baby-log/ 에서 열립니다.

## 3. 휴대폰에 설치 (재현·아내·장모님 각자)

서버 주소는 공개 저장소에 넣지 않고, **가족용 링크**로 한 번만 전달합니다.

```
https://sung-jaehyun.github.io/baby-log/#s=<웹 앱 URL>
```

1. 위 가족용 링크를 카톡 등으로 받아 **크롬**으로 엽니다(서버 주소가 휴대폰에 저장됨).
2. 자기 PIN 4자리를 입력합니다. 처음 PIN이면 새 PIN으로 바꾸라는 창이 뜹니다.
3. 오른쪽 위 **⋮ → 앱 설치**(또는 홈 화면에 추가)를 누릅니다.
4. 홈 화면의 아이콘으로 실행하면 전체화면 앱처럼 열립니다.

## 미리보기(데모)

서버 주소 칸에 `demo`, PIN `1111` → 휴대폰 안에서만 동작하는 예시 데이터로 체험할 수 있습니다.
